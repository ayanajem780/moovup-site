# moovup-site

Site du Complexe Moov'Up Sports (squelette).

- `index.html` : tout le site (page d'accès membre / visiteur, espace visiteur, espace membre)
- `assets/logo.png` : logo
- `assets/salle.jpg` : photo de la salle (à remplacer par une version en grande taille)

Les textes marqués « à remplir », « à confirmer » ou « exemples à remplacer » sont des emplacements.
Les formulaires (connexion, réservation de visite) ne sont pas encore branchés.
